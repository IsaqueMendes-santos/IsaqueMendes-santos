# Sobre Mim

Meu nome é Isaque, tenho 16 anos e sou desenvolvedor em formação pelo SENAI 438. Atualmente, busco aprimorar minhas competências técnicas em desenvolvimento de software, aplicando conceitos teóricos em projetos práticos e acadêmicos.

## Objetivos Profissionais
O objetivo principal do meu perfil é documentar minha evolução na programação, armazenar códigos-fonte de projetos desenvolvidos e colaborar com outros desenvolvedores. Busco constantemente aprender novas tecnologias, metodologias ágeis e boas práticas de arquitetura de sistemas para construir soluções eficientes e escaláveis.

## Formação Acadêmica
* Desenvolvimento de Software — SENAI 438

## Competências e Tecnologias em Desenvolvimento
* Lógica de programação e algoritmos
* Versionamento de código com Git e GitHub
* Desenvolvimento de aplicações estruturadas
